# E-Commerce Analytics Dashboard | Power BI

## Overview

This repository contains an interactive E-Commerce Analytics Dashboard developed using Power BI. The dashboard helps analyze sales performance, profit trends, order metrics, and regional insights to support business decision-making.

## Files Included

* `Ecommerce_Dataset
* `Dashboard_Screensho
* `Project documentation

## Features

* Total Sales Analysis
* Average Profit Tracking
* Order Count Monitoring
* Profit Margin Analysis
* Regional Performance Insights
* Interactive Filters and Slicers
* Automated Business Insights

## Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization
